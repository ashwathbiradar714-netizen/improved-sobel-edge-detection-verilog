# Improved Hardware-Oriented Sobel Edge Detection Using Verilog HDL

## Project Overview
This project focuses on implementing and comparing different Sobel edge detection techniques using Verilog HDL and Xilinx Vivado 2020.2.

The system processes grayscale images and identifies important edges and boundaries.

## Objectives
- Implement conventional Sobel edge detection.
- Develop a modified Sobel approach.
- Explore Winograd-based Sobel optimization.
- Simulate the designs using Verilog HDL.
- Compare the generated edge detection outputs.

## Technologies Used
- Verilog HDL
- Xilinx Vivado 2020.2
- Python for image conversion and analysis, where used.

## Image Specifications
- Image format: Grayscale
- Resolution: 256 × 256 pixels
- Pixel depth: 8 bits

## Project Workflow
1. Input grayscale image.
2. Convert image pixels into hexadecimal data.
3. Perform Sobel edge detection.
4. Generate simulation output.
5. Convert output data into an image.
6. Compare the results.
